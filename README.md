# PixIT
Pixit is a photo-editing tool that allows you to customize your image in real
time. Using the webcam as live data and the mouse to place the image on the
screen, it creates a playful environment to experiment with filters and blend
modes. This tool not only presents key design concepts, but also allows you to
see and present yourself creatively.
The project was created in response to a design brief that highlights creative
ways of representing data, using the webcam and the mouse as data input.
Coding experimentation

Tools: HTML, CSS, JavaScript, p5.js
